# GitHub Context

Status: completed by [PR #509](https://github.com/footnote-ai/footnote/pull/509) for [issue #491](https://github.com/footnote-ai/footnote/issues/491). The backend provides bounded, read-only GitHub context; the feature remains fail-open and its results are not represented as a complete repository or history search.

See the maintained [GitHub Context architecture](../../architecture/context-integrations/github.md) for current scope and limitations.
