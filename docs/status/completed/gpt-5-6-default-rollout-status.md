# GPT-5.6 Default Rollout

Status: rollout delivered by [PR #457](https://github.com/footnote-ai/footnote/pull/457). GPT-5.6 Terra became the default OpenAI generation model, with Luna and Sol assigned to their intended profile roles. The implementation added concrete model IDs, explicit reasoning support, cost accounting, and privacy-preserving safety identifiers.

This closeout does not claim representative live-model evaluation is complete. The [model behavior baseline](../model-behavior-baseline.md) records that a live runner remains deferred. Backend model-strength escalation is a separate open follow-up, [#564](https://github.com/footnote-ai/footnote/issues/564).
