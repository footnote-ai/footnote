# Footnote Codex themes

These files are portable Codex desktop Appearance import strings. Each file
contains one complete `codex-theme-v1:` payload and must be imported into the
matching Light or Dark theme section.

The `.codex-theme.txt` suffix is intentional: the prefix makes the payload a
copyable import string rather than a standalone JSON document. The theme files
are personal-tooling artifacts and are not consumed by Footnote's runtime.

The referenced fonts are documented separately in `../fonts`. Importing a
theme does not install or distribute those fonts.
